Colorir função fill

Para colorir usamos a função fill que traduzindo preenchimento colocamos a variaveis RGB assim fill(Red,Green,Blue); sendo esta variáveis de 0 a 255 sendo que o fill vai colorir todas as figuras abaixo, caso queira colorir cada figura de uma cor diferente, antes de cada figura precisará de um fill com a cor desejada. Exemplo:

function setup() {
createCanvas(400, 400);
}

function draw() {
background(150, 150, 150);
fill(255,0,0);
square(60,30,10);
square(60,40,10);
}

Desta forma os dois quadradinhos será colorido com a cor vermelha

function setup() {
createCanvas(400, 400);
}

function draw() {
background(150, 150, 150);
fill(255,0,0);
square(60,30,10);
fill(0,255,0);
square(60,40,10);
}

Desta outra forma o primeiro quadradinho será colorido de vermelho e o segundo de verde
